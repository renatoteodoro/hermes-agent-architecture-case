# Checklist de verificação

## API e transporte

- [x] Endpoint sem credencial rejeitado com HTTP 401.
- [x] Endpoint autenticado respondeu HTTP 200.
- [x] Serviço de origem restrito a loopback.
- [x] Rota externa publicada por HTTPS.

## Ferramentas e identidade

- [x] Catálogo MCP descoberto pelo cliente.
- [x] Vinte e uma ferramentas disponíveis na integração autenticada.
- [x] Sessão externa identificada separadamente.
- [x] Tentativa de uso de terminal bloqueada em sessão restrita.

## Fluxo de aprovação

- [x] Saída registrada como aguardando aprovação.
- [x] Ações de aprovar, recusar e pedir ajuste representadas no estado.
- [x] Decisão persistida para processamento posterior.
- [x] Arquivamento em nuvem confirmado após aprovação.

## Privacidade

- [x] Nenhuma chave incluída neste repositório.
- [x] Endereços privados e nomes do projeto original omitidos.
- [x] Nenhum conteúdo de cliente incluído.
